# HACKALEM AI — ИИ-ассистент ekt.kz

Прототип чат-ассистента для интернет-магазина электротехнической продукции.

## Что умеет прототип

- отвечает по каталогу: характеристики, цена, наличие и сертификаты;
- предлагает аналог, если выбранный товар отсутствует;
- отвечает на вопросы об оплате, доставке и минимальной партии;
- не меняет корзину без явного подтверждения клиента;
- проверяет остаток и количество перед добавлением;
- показывает прямую ссылку на актуальную корзину;
- архитектура оставляет место для загрузки Excel, Word, PDF и JPEG как следующего шага интеграции.

## Быстрый запуск

Требуется Python 3.11+.

```bash
cd backend
python -m venv .venv
source .venv/bin/activate       # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Для тестов установите `backend/requirements-dev.txt` и выполните `pytest backend/tests`.

Откройте в браузере: http://127.0.0.1:8000

API-документация доступна по адресу: http://127.0.0.1:8000/docs

## Демо-запросы

Попробуйте в чате:

- `Есть ли автомат ВА47-29 2P C16?`
- `Покажи характеристики и сертификат ВА47-29 2P C16`
- `У позиции КАБЕЛЬ ВВГнг-LS 3x2.5 нет в наличии, что есть похожего?`
- `Какие условия оплаты и доставки?`
- `добавь 2 штуки ВА47-29 2P C16 в корзину`

Для добавления ассистент сначала попросит подтверждение. Только ответ `да, добавь` или аналогичное явное подтверждение изменит корзину.

## Структура проекта

```text
.
├── .vscode/                 # настройки и задачи VS Code
├── backend/
│   ├── app/
│   │   ├── main.py          # HTTP API и раздача интерфейса
│   │   ├── catalog.py       # поиск товаров и аналогов
│   │   ├── chat.py          # диалоговая логика и подтверждение корзины
│   │   └── cart.py          # корзина в памяти для демо
│   ├── data/products.json   # синтетический каталог
│   └── requirements.txt
├── frontend/                # web-интерфейс чат-ассистента
├── docs/                    # план, архитектура и критерии демо
└── .env.example
```

## Архитектура и данные

Подробности находятся в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), план спринта — в [docs/PROJECT_PLAN.md](docs/PROJECT_PLAN.md).

В демо используется `backend/data/products.json`. В продуктивной версии этот слой заменяется адаптером к тестовому API или выгрузке партнёра. Платёжные данные не принимаются и не хранятся.

## Командная работа

1. Сначала заменить синтетический каталог на выгрузку партнёра, сохранив поля из `products.json`.
2. Подключить LLM/RAG через отдельный слой `chat.py`, не давая модели прямого доступа к изменению корзины.
3. Перед демо прогнать сценарии из `docs/DEMO_CHECKLIST.md`.
4. Для командной разработки создавать отдельные ветки: `feature/catalog`, `feature/chat`, `feature/ui`.

Для открытия в VS Code используйте файл `hackalem-ai.code-workspace` или откройте корневую папку проекта.
