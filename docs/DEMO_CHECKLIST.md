# Чек-лист демонстрации

- [ ] Спросить наличие существующего артикула.
- [ ] Показать характеристики и сертификат.
- [ ] Спросить товар с нулевым остатком и получить аналог с объяснением.
- [ ] Спросить про оплату, доставку и минимальную партию.
- [ ] Попросить добавить товар без подтверждения — корзина не меняется.
- [ ] Написать `да, добавь` — товар добавляется.
- [ ] Проверить, что количество не превышает остаток.
- [ ] Перейти по ссылке на корзину.
- [ ] Проверить отображение на узком экране.
