# Архитектура прототипа

```text
Браузер
  │
  ├── GET /                    web-интерфейс
  ├── POST /api/chat          ответ ассистента и pending-действие
  ├── POST /api/chat/upload   анализ фото, PDF, Word, Excel и CSV
  ├── POST /api/cart/confirm  явное подтверждение добавления
  └── GET /api/cart/{session} актуальное состояние корзины
          │
          ├── ChatService      правила диалога и intent
          ├── CatalogService   поиск товара и аналогов
          └── CartService      серверная проверка остатков
                    │
              products.json
```

## Важные границы безопасности

1. Модель или парсер чата не изменяет корзину напрямую.
2. Добавление возможно только через отдельное подтверждение клиента.
3. Сервер повторно проверяет остаток и ограничивает количество.
4. Если данных каталога нет, ассистент говорит, что не может подтвердить информацию.
5. Платёжные данные не принимаются, не логируются и не сохраняются.
