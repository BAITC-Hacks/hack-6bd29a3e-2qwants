# План работы: партнёр ekt.kz и frontend/logic developer

## Граница текущего этапа

На этапе визуального прототипа backend не меняем. Работаем поверх статической demo-версии, чтобы быстро согласовать внешний вид, сценарии и пользу Quant.

Источник дизайна и предметной области — текущий сайт ekt.kz. Quant добавляется как встроенный слой помощника поверх поиска, каталога и корзины.

## Что нужно от партнёра ekt.kz

### 1. Данные каталога

Партнёр предоставляет тестовую выгрузку или API с полями:

- артикул;
- название;
- категория;
- бренд;
- характеристики;
- цена;
- остаток;
- склад и город;
- единица измерения: штука, метр, упаковка;
- сертификат или ссылка на сертификат;
- доступность самовывоза и доставки.

Для демо достаточно 30–100 товаров из нескольких категорий, но структура должна быть похожа на будущий полный каталог.

### 2. Правила магазина

Нужно подтвердить:

- правила оплаты;
- минимальную партию;
- доставку по городам;
- самовывоз;
- ограничения по товарам и остаткам;
- правила замены отсутствующей позиции;
- когда нужно передавать вопрос менеджеру.

### 3. Дизайн и бренд

Партнёр предоставляет или подтверждает:

- логотип;
- фирменные цвета и шрифты;
- допустимый стиль карточки товара;
- реальные изображения товаров;
- тексты для пустых состояний, ошибок и контактов менеджера.

### 4. Приёмка

Партнёр проверяет:

- корректность товарных данных;
- правильность рекомендаций аналогов;
- тексты по оплате и доставке;
- соответствие прототипа визуальной логике ekt.kz;
- возможность встроить Quant в существующий сайт.

### 5. Что партнёр не делает на текущем этапе

- не пишет frontend;
- не переносит каталог вручную в интерфейс;
- не меняет backend прототипа;
- не отвечает за состояние чата в браузере.

## Что делаешь ты: frontend и логика продукта

### Этап A — визуальная база

- собрать светлый интерфейс, близкий к структуре ekt.kz;
- повторить шапку, верхнюю панель, поиск, каталог, карточки и корзину;
- добавить переключатель «Базовый ekt.kz / С Quant»;
- вынести иконку Quant в отдельный файл;
- проверить desktop и mobile.

### Этап B — интерфейс Quant

- floating-кнопка «Спросить Quant»;
- раскрываемая панель в стиле сайта;
- приветствие и объяснение возможностей;
- быстрые вопросы;
- состояния loading, error, empty;
- карточки найденных товаров внутри диалога;
- сравнение двух-трёх товаров;
- объяснение, почему предложен аналог;
- кнопка передачи менеджеру.

### Этап C — клиентская логика

- хранить историю текущего диалога;
- работать с `session_id`;
- блокировать повторную отправку во время ответа;
- отображать подтверждение перед корзиной;
- обновлять счётчик и сумму корзины;
- показывать ссылку на оформление;
- не добавлять товар по одному клику без подтверждения пользователя.

### Этап D — подготовка к API

Frontend не придумывает правила остатков и цены. Он принимает согласованный JSON-контракт:

- `/api/chat` — ответ ассистента;
- `/api/products` — список товаров;
- `/api/cart/{session_id}` — корзина;
- `/api/cart/confirm` — подтверждённое добавление.

До готовности реального API используются mock-данные в визуальном прототипе. После появления API меняется только источник данных, а UI и сценарий остаются стабильными.

## Совместные контрольные точки

| Точка | Партнёр | Ты |
| --- | --- | --- |
| 1. Визуальная база | подтверждает соответствие ekt.kz | собираешь clone-layout |
| 2. Данные | даёт тестовую выгрузку | отображаешь карточки |
| 3. Рекомендации | подтверждает релевантность аналогов | показываешь comparison UI |
| 4. Корзина | подтверждает бизнес-правила | реализуешь confirmation flow |
| 5. Демо | проверяет факты | проводишь сценарий |

## Definition of Done для твоей части

- ссылка на визуальный demo открывается без backend;
- есть режим базового ekt.kz и режим с Quant;
- один и тот же товар виден в каталоге и в чате;
- сравнение показывает минимум цену, наличие и характеристики;
- аналог сопровождается объяснением;
- корзина меняется только после «да, добавь»;
- дизайн не использует прежний тёмно-синий/yellow-концепт;
- партнёр может открыть demo и оставить конкретные корректировки по экрану.
